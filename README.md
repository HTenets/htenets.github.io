## 特性

- **设计与用户体验** - 响应式布局、深色/浅色模式、本地化界面语言，以及深色模式图片。
- **内容管理** - 置顶文章、层级分类、热门标签、自动生成目录，以及最后修改日期。
- **丰富的文本支持** - 语法高亮、数学表达式、Mermaid 图表和流程图，以及嵌入式媒体。
- **交互与推广** - 内置搜索、多评论系统，以及 Atom 订阅源。
- **系统与优化** - PWA 支持、集成网页分析，以及高级 SEO 性能。
